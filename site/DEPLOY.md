# Curva Aberta — site

Esta pasta contém a versão estática da base de conhecimento para GitHub Pages.
Os módulos e materiais são mantidos em `src/data/`. Atualizações do conteúdo do site devem ser feitas nesta pasta e publicadas pela ação `pages.yml`.

```sh
npm install
npm run dev
npm run build
```

O endereço padrão é `https://hills808.github.io/base-conhecimento-desenvolvimento/`.
O progresso é salvo no navegador do visitante, sem conta nem sincronização entre domínios.
O conteúdo do repositório continua disponível nos guias Markdown.

A publicação é automática após alterações em `site/` na branch `main`.
