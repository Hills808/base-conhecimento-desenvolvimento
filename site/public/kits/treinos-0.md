# Treinos de autonomia — módulo 0

Responda antes de ler a análise. Após a comparação, faça a variação e registre o resultado.

## Nível 0
### Caso novo
Você tem duas sessões de 25 minutos e quer entender uma resposta HTTP. Defina uma entrega possível e o que ficará para depois.

### Análise esperada
Uma entrega observável é apontar método, status e dois campos numa chamada. Instalação de ferramentas ou um curso completo podem ficar para outra sessão. A meta deve caber no tempo e ter critério de conferência.

### Transferência
Uma das sessões foi cancelada. Reduza a entrega sem abandonar a prática.

### Evidências
- [ ] Justifiquei a decisão com uma evidência.
- [ ] Corrigi as divergências após comparar.
- [ ] Fiz a mudança proposta e expliquei o resultado.

## Nível 1
### Caso novo
Depois de ler uma aula, você reconhece todos os termos, mas não consegue explicar nenhum sem olhar. Monte a próxima sessão.

### Análise esperada
Comece tentando recuperar a explicação, identifique o termo que faltou, consulte só esse trecho e use um exemplo novo. Familiaridade com a página não demonstra recuperação.

### Transferência
Explique o conceito para alguém que não conhece a ferramenta.

### Transferência
