## Como transformar os materiais em aprendizado

1. Escolha um módulo e uma habilidade que deseja praticar.
2. Use uma aula ou tutorial principal; consulte as outras fontes quando surgir uma dúvida.
3. Faça o exercício ou projeto sugerido e registre o que conseguiu realizar.
4. Retome o catálogo para escolher o próximo assunto conforme o resultado que precisa alcançar.

As aplicações descritas são **objetivos de estudo**. Elas dependem de prática; o catálogo reúne materiais e propostas, não garante domínio ao concluir uma leitura.
