### Checklist mínimo de interface

- funciona apenas com teclado;
- tem foco visível e ordem de navegação coerente;
- usa elementos HTML adequados antes de ARIA;
- mantém contraste e texto legível;
- informa erros junto aos campos;
- respeita preferências de movimento;
- entrega conteúdo essencial com conexão lenta;
- mede desempenho em vez de depender apenas da percepção local.

## Projeto sugerido

Construa uma interface para a API do guia de backend com:

- design responsivo;
- navegação por teclado e leitor de tela;
- estados de carregamento, vazio, erro e sucesso;
- formulários validados;
- testes de componentes e fluxo principal;
- orçamento de performance;
- modo offline simples ou estratégia explícita para falhas de rede.
