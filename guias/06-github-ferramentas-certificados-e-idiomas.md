## GitHub: repositórios e prática

### Onde encontrar bons repositórios

- [GitHub Topics](https://github.com/topics) — pesquise por `learning`, `beginner-friendly`, `dotnet`, `api` e outros temas.
- [Awesome Lists](https://github.com/sindresorhus/awesome) — índice de listas curadas; verifique manutenção e qualidade de cada item. 🧩 🌐
- [Project Based Learning](https://github.com/practical-tutorials/project-based-learning) — escolha projetos por linguagem. 🧩 🌐
- [Public APIs](https://github.com/public-apis/public-apis) — APIs públicas para projetos; leia os termos de cada serviço. 🧩 🌐
- [API List](https://apilist.fun/) — catálogo pesquisável de APIs públicas. 📚 🌐

### Contribuição open source

- [First Contributions](https://github.com/firstcontributions/first-contributions) — primeiro pull request guiado. 🧩 🌐
- [Good First Issue](https://goodfirstissue.dev/) — busca de issues para iniciantes. 📚 🌐
- [Up For Grabs](https://up-for-grabs.net/) — projetos com tarefas de entrada. 📚 🌐
- [CodeTriage](https://www.codetriage.com/) — receba issues de projetos para ajudar. 📚 🌐

Antes de contribuir, leia `README`, `CONTRIBUTING`, Código de Conduta, licença e issues existentes. Comece por documentação, reprodução de bugs ou testes quando ainda não conhece a base de código.

### Prática de programação

- [Exercism](https://exercism.org/) — exercícios por linguagem. 📚 🌐
- [Codewars](https://www.codewars.com/) — desafios organizados por dificuldade. 📚 🌐
- [LeetCode](https://leetcode.com/) — algoritmos e entrevistas; possui conteúdo gratuito e pago. 📚 🌐
- [HackerRank](https://www.hackerrank.com/) — desafios por assunto. 📚 🌐
- [Advent of Code](https://adventofcode.com/) — desafios anuais. 📚 🌐
- [Edabit](https://edabit.com/) — exercícios curtos; confira os limites do plano atual. 📚 🌐

## Idiomas para tecnologia

Para desenvolvimento, o objetivo é entender documentação, vídeos, erros, README e tickets, além de explicar o próprio código. Inglês é a prioridade prática; outros idiomas podem entrar depois por interesse ou oportunidade.

### Base estruturada

- [Kultivi — Inglês](https://kultivi.com/curso/ingles?lang=pt) — curso em português; confira as condições atuais do certificado. 🎓
- [Kultivi — Aprendizado acelerado de idiomas](https://kultivi.com/curso/aprendizado-acelerado-de-idiomas) — método, revisão e prática. 🎓
- [OpenLearn — Languages](https://www.open.edu/openlearn/languages) — cursos livres; declarações e badges variam por curso. 🏅 🌐

### Inglês real: ouvir, ler e falar

- [engVid](https://www.engvid.com/english-lessons/) — aulas filtráveis por nível e tema. 📚 🌐
- [Breaking News English](https://breakingnewsenglish.com/) — notícias por nível, com áudio e exercícios. 📚 🌐
- [BBC Learning English](https://www.bbc.co.uk/learningenglish/) — vídeos e lições curtas. 📚 🌐
- [YouGlish](https://youglish.com/) — pronúncia em exemplos reais de vídeo. 📚 🌐
- [Cambridge Dictionary](https://dictionary.cambridge.org/) — significado, pronúncia e exemplos. 📚 🌐
- [Anki](https://apps.ankiweb.net/) — revisão espaçada com cartões próprios. 📚 🌐

### Rotina de 25 minutos para dev

1. **10 min — curso estruturado:** Kultivi ou OpenLearn.
2. **10 min — conteúdo real:** documentação, engVid ou Breaking News English.
3. **5 min — produção:** registre três expressões e escreva uma frase sobre o código estudado.

Mude gradualmente ferramentas e mensagens de commit para inglês. Não traduza cada palavra; pesquise apenas o que bloquear o entendimento.
