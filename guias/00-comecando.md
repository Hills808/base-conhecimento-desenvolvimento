## A ordem universal

1. **Lógica + Git** — antes de qualquer framework.
2. **Uma linguagem principal** — faça exercícios e pequenos programas.
3. **Banco + HTTP/API** — a base de sistemas reais.
4. **Projeto com GitHub** — transforme conteúdo em experiência.
5. **Testes, Docker, CI/CD e cloud** — evolua o projeto para um padrão profissional.

## Um ciclo de estudo que funciona

Para cada assunto:

1. defina algo pequeno que deseja conseguir fazer;
2. escolha um único curso ou tutorial principal;
3. consulte a documentação oficial quando surgir uma dúvida;
4. resolva exercícios sem copiar a solução;
5. construa um projeto curto;
6. escreva o que aprendeu e o próximo passo.

## Projeto progressivo sugerido

Escolha um problema simples — tarefas, finanças pessoais, biblioteca ou catálogo — e evolua o mesmo projeto:

1. programa de terminal com dados em memória;
2. persistência em banco de dados;
3. API HTTP documentada;
4. interface web ou mobile;
5. autenticação e validação;
6. testes automatizados;
7. container, CI/CD e deploy;
8. logs, métricas, alertas e revisão de segurança.

Assim, cada etapa reaproveita o que já foi aprendido e produz evidências práticas para o portfólio.
